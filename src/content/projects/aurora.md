Aurora is a real-time data pipeline that ingests telemetry from satellite simulators and surfaces anomalies before they cascade into system failures. Built for throughput and fault tolerance, it processes millions of events per second with automatic backpressure handling and graceful degradation. Carol defined the product requirements around operator dashboards and alert thresholds, while Dave documented the streaming API and wrote the integration guides that onboard new platform users within hours instead of days.
