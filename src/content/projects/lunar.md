Lunar is an interface toolkit that provides accessible, themeable components for modern web applications. From navigation primitives to complex data visualizations, every component ships with keyboard support, screen reader annotations, and responsive behavior out of the box. Alice engineered the state-management layer and optimized the build pipeline for tree-shaking, while Dave wrote usage guidelines and accessibility checklists that help product teams adopt components correctly the first time.
