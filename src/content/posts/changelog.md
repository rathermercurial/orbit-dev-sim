This changelog tracks every public release of the Orbit platform. Versions follow semantic versioning, and each entry includes a summary of features, fixes, and breaking changes alongside the contributors who shipped them.

**1.2.0** — Released 2024-06-01
Added multi-region deployment support with automatic failover. Integrated the Stellar content distribution network for edge-cached documentation. Introduced anomaly-based alerting in the Solar dashboard. Improved cold-start latency across all regions.

**1.1.0** — Released 2024-04-15
Launched the Lunar interface toolkit with twenty accessible components. Added cursor-based pagination to all list endpoints. Expanded the Cosmos documentation platform with versioned guides and interactive code snippets.

**1.0.0** — Released 2024-01-01
Initial public release of the Orbit platform. Shipped Aurora data pipeline, Solar monitoring dashboard, and Cosmos documentation library. Included command-line interface with authentication, project initialization, and deployment workflows.

**0.9.0** — Released 2023-10-12
Final beta before public launch. Stabilized the Nebula design system tokens. Added responsive layouts and dark mode support. Conducted accessibility audit with third-party verification.

We publish release notes for every minor and major version. Patch releases are documented in the repository releases page. If you notice a discrepancy between this changelog and the actual behavior of the platform, please open an issue so we can investigate.
